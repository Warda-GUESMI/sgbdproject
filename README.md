📋 Description


Application JavaFX de gestion commerciale connectée à Oracle Database. Permet de gérer les articles (stock, prix, TVA), les commandes clients et les livraisons avec suivi en temps réel.


✨ Fonctionnalités

Articles : CRUD complet, gestion stock et prix


Commandes : Suivi des états (En cours, Prête, Livrée)


Livraisons : Gestion livreurs et modes de paiement


Interface moderne avec tableaux interactifs et codes couleur

🛠️ Technologies

Java 17 + JavaFX (Pattern MVC)
Oracle Database (JDBC)
CSS pour le design
